# Actuarial Financial Modeling Portfolio

This repository contains five Excel-based life insurance modeling projects developed from university coursework. The portfolio focuses on model structure, actuarial calculations, profit emergence, scenario analysis, asset valuation, and financial reporting.

## Projects

### Case 1. Premium and Reserve Foundations

Calculates premiums and provisions for term-life and endowment contracts in yearly and monthly models.

[Project details](00-premium-and-reserve-foundations/README.md)

### Case 2. Life Insurance Reserving and Profit Analysis

Calculates premiums and actuarial provisions, including net provisions, deferred acquisition costs, and expense reserves. It also projects balance sheets, profit and loss, expected results, dividends, and present values.

[Project details](01-reserving-and-profit-analysis/README.md)

### Case 3. Scenario-Based Actuarial Profit Decomposition

Compares cost-price and best-estimate scenarios and decomposes insurance profit into mortality, expense, interest, and surrender results.

[Project details](02-scenario-pnl-decomposition/README.md)

### Case 4. Profit Sharing and First-Year Bookings

Determines first-year profit sharing and accounting bookings using annuity-bond and bullet-bond cash-flow models.

[Project details](04-profit-sharing-and-bookings/README.md)

### Case 5. Market-Value Liability and Yield-Curve Analysis

Projects liabilities and profit on a market-value basis using yield curves, best-estimate assumptions, and scenario adjustments. It compares present values across accounting approaches.

[Project details](03-market-value-liability-analysis/README.md)

## Skills demonstrated

- Life insurance cash-flow modeling
- Premium and reserve calculations
- Deferred acquisition cost and expense reserve analysis
- Mortality, surrender, expense, and interest assumptions
- Balance sheet and profit-and-loss projection
- Scenario and experience-result analysis
- Yield-curve discounting and market-value liability analysis
- Excel formula design, model checks, and visualization

## How to review

Each project folder contains:

- `model.xlsx`: the working Excel model
- `README.md`: project scope and workbook guide
- `images/`: workbook overview and model preview

Open the `Portfolio Overview` tab first, followed by the principal calculation tab identified in each project README.
